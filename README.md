A single unsent confession, written exactly as it was typed and never sent: a To: line naming who it was meant for (a role and a place, no full name or handle) and the message itself on one line, with no explanation after it. The confession is a small, specific shame — a lie about who the antibiotics were for — followed by the ongoing avoidance ritual it left behind.

## Run it

```sh
python3 main.py
```

This writes the confession to `/output/entry.txt` (178 characters total; the message itself is 143 characters).
